# LCD-and-Keypad-Interfacing-Using-STM32F407ZGT6
Developed an embedded system integrating a 16×2 LCD and a 4×4 matrix keypad with the STM32F407ZGT6 microcontroller. Created custom libraries for LCD communication and keypad scanning to display text, numbers, timers, and user inputs, including hexadecimal characters (A–F).
